Projects

Seven projects: BoardGames Analyzer, Talent_AI, JourneySet, PX Mart Finder, Taiwan Fare Finder, Prambanan Batik, Three Frogs

Four have live demos, and the code for all seven is on GitHub.

BoardGames Analyzer

Python, Streamlit, scikit-learn, HuggingFace

Live Demo GitHub

A board game recommender with three modes. It combines TF-IDF, MiniLM embeddings, and DistilBERT sentiment analysis, explains each recommendation, and runs as an interactive Streamlit dashboard.

Talent_AI

Python, spaCy, FAISS, OpenAI

Live Demo GitHub

Parses resumes into structured candidate data and ranks candidates against a job description with semantic search. It anonymizes personal information, adds OpenAI-generated insights, and gives recruiters a Streamlit dashboard.

JourneySet

React, TypeScript, Supabase, Tailwind

Live Demo GitHub

A weekly planner with a goal tracker and an event calendar. It stores data in Supabase and falls back to localStorage when the connection drops.

PX Mart Finder

React, TypeScript, Vite, Fuse.js

Live Demo GitHub

A prototype for finding products in one PX Mart (全聯) branch in Taiwan. It has fuzzy search with synonyms, shows the aisle and shelf for each item, and works in two languages on any screen size.

Taiwan Fare Finder

Flutter, Dart, TDX API

GitHub

A Flutter app that compares public transit fares across Taiwan (HSR, TRA, MRT, bus, and YouBike) using live data from the TDX API. It caches results for offline use and supports multiple languages.

Prambanan Batik

PHP, MySQL, Vanilla JS

GitHub

A catalog and review site for Indonesian batik. It has an admin panel, CSV bulk import, an SEO sitemap and robots.txt, and protection against brute-force logins.

Three Frogs

PHP, MySQL, jQuery

GitHub

A website for a board game café in Surabaya. Customers can browse about 218 games, create an account, and book a table, and the server enforces booking hours and cancellation limits.
