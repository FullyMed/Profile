BoardGames Analyzer

Python, Streamlit, scikit-learn, HuggingFace

Demo Langsung GitHub

Sistem rekomendasi board game dengan tiga mode. Sistem ini menggabungkan TF-IDF, embedding MiniLM, dan analisis sentimen DistilBERT, menjelaskan alasan setiap rekomendasi, dan berjalan sebagai dashboard Streamlit interaktif.

Talent_AI

Python, spaCy, FAISS, OpenAI

Demo Langsung GitHub

Mengubah CV menjadi data kandidat yang terstruktur, lalu mengurutkan kandidat berdasarkan deskripsi pekerjaan dengan pencarian semantik. Sistem ini menganonimkan data pribadi, menambahkan insight dari OpenAI, dan menyediakan dashboard Streamlit untuk perekrut.

JourneySet

React, TypeScript, Supabase, Tailwind

Demo Langsung GitHub

Planner mingguan dengan pelacak target dan kalender acara. Datanya tersimpan di Supabase dan beralih ke localStorage saat koneksi terputus.

PX Mart Finder

React, TypeScript, Vite, Fuse.js

Demo Langsung GitHub

Prototipe untuk mencari produk di satu cabang PX Mart (全聯) di Taiwan. Ada pencarian fuzzy dengan sinonim, lokasi lorong dan rak tiap produk, dan antarmuka dua bahasa yang nyaman dipakai di layar mana pun.

Taiwan Fare Finder

Flutter, Dart, TDX API

GitHub

Aplikasi Flutter untuk membandingkan tarif transportasi umum di Taiwan (HSR, TRA, MRT, bus, dan YouBike) dengan data langsung dari TDX API. Aplikasi ini menyimpan hasil untuk dipakai offline dan mendukung beberapa bahasa.

Prambanan Batik

PHP, MySQL, Vanilla JS

GitHub

Situs katalog dan ulasan batik Indonesia, lengkap dengan panel admin, impor massal CSV, sitemap dan robots.txt untuk SEO, serta perlindungan login dari serangan brute-force.

Three Frogs

PHP, MySQL, jQuery

GitHub

Situs untuk sebuah kafe board game di Surabaya. Pelanggan bisa melihat sekitar 218 board game, membuat akun, dan memesan meja, sementara server mengatur jam booking dan batas pembatalan.
