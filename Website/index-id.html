Tentang Saya

Saya kuliah Teknik Informatika di Asia University, Taichung, Taiwan. Saya orang Indonesia, dan sebagian besar pekerjaan saya sejauh ini mengharuskan saya berpindah antara Bahasa Indonesia, Inggris, dan Mandarin.

Di kampus, saya asisten mahasiswa di International College dan membantu mahasiswa internasional mengurus dokumen dalam Bahasa Inggris dan Mandarin. Saya juga asisten pengajar di ELTA di sekolah-sekolah lokal, dan bekerja paruh waktu di PX Mart.

Di waktu luang, saya membuat aplikasi, misalnya pencari tarif transportasi di Taiwan dan sistem rekomendasi board game. Kalau Anda sedang mengerjakan sesuatu di bidang teknologi atau pendidikan, saya ingin mendengarnya.
