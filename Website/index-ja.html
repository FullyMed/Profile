プロジェクト

7つのプロジェクト： BoardGames Analyzer、Talent_AI、JourneySet、PX Mart Finder、Taiwan Fare Finder、Prambanan Batik、Three Frogs

4つはデモを公開していて、7つすべてのコードはGitHubにあります。

BoardGames Analyzer

Python, Streamlit, scikit-learn, HuggingFace

ライブデモ GitHub

3つのモードを持つボードゲーム推薦システム。TF-IDF、MiniLMの埋め込み、DistilBERTによる感情分析を組み合わせ、推薦の理由も表示します。Streamlitのダッシュボードで動きます。

Talent_AI

Python, spaCy, FAISS, OpenAI

ライブデモ GitHub

履歴書を構造化された候補者データに変換し、求人内容に合わせてセマンティック検索で候補者を順位付けします。個人情報の匿名化、OpenAIによる分析、採用担当者向けのStreamlitダッシュボードを備えています。

JourneySet

React, TypeScript, Supabase, Tailwind

ライブデモ GitHub

週ごとの予定表に目標トラッカーとイベントカレンダーを組み合わせたプランナー。データはSupabaseに保存し、接続が切れたときはlocalStorageに切り替わります。

PX Mart Finder

React, TypeScript, Vite, Fuse.js

ライブデモ GitHub

台湾のPX Mart（全聯）1店舗で商品を探すためのプロトタイプ。同義語に対応したあいまい検索、商品ごとの通路と棚の表示、スマホでも使える2言語のUIがあります。

Taiwan Fare Finder

Flutter, Dart, TDX API

GitHub

台湾の公共交通機関（高鐵・台鉄・MRT・バス・YouBike）の運賃を、TDX APIのリアルタイムデータで比較できるFlutterアプリ。オフライン用のキャッシュと多言語表示に対応しています。

Prambanan Batik

PHP, MySQL, Vanilla JS

GitHub

インドネシアのバティック（ろうけつ染め）の商品カタログ兼レビューサイト。管理画面、CSV一括インポート、SEO用のsitemapとrobots.txt、ログインへのブルートフォース攻撃対策があります。

Three Frogs

PHP, MySQL, jQuery

GitHub

スラバヤにあるボードゲームカフェのためのWebサイト。約218種類のゲームの閲覧、アカウント登録、テーブル予約ができ、予約可能時間とキャンセル制限はサーバー側で管理しています。
