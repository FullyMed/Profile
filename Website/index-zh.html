BoardGames Analyzer

數據

有三種推薦模式的桌遊推薦系統，結合 TF-IDF、MiniLM 向量和 DistilBERT 情感分析，會說明每個推薦的理由，並用 Streamlit 互動儀表板呈現。

  • Python
  • Streamlit
  • scikit-learn
  • HuggingFace
線上預覽 GitHub

Talent_AI

數據

把履歷解析成結構化的應徵者資料，再用語意搜尋依職缺描述替應徵者排序。系統會將個人資料匿名化、加入 OpenAI 產生的分析，並提供招募人員使用的 Streamlit 儀表板。

  • Python
  • spaCy
  • FAISS
  • OpenAI
