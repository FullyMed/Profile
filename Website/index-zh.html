作品

七個專案： BoardGames Analyzer、Talent_AI、JourneySet、PX Mart Finder、Taiwan Fare Finder、Prambanan Batik、Three Frogs

其中四個有線上展示，七個專案的程式碼都放在 GitHub。

BoardGames Analyzer

Python, Streamlit, scikit-learn, HuggingFace

線上預覽 GitHub

有三種推薦模式的桌遊推薦系統，結合 TF-IDF、MiniLM 向量和 DistilBERT 情感分析，會說明每個推薦的理由，並用 Streamlit 互動儀表板呈現。

Talent_AI

Python, spaCy, FAISS, OpenAI

線上預覽 GitHub

把履歷解析成結構化的應徵者資料，再用語意搜尋依職缺描述替應徵者排序。系統會將個人資料匿名化、加入 OpenAI 產生的分析，並提供招募人員使用的 Streamlit 儀表板。

JourneySet

React, TypeScript, Supabase, Tailwind

線上預覽 GitHub

每週規劃工具，包含目標追蹤和行事曆。資料存在 Supabase，斷線時改用 localStorage 保存。

PX Mart Finder

React, TypeScript, Vite, Fuse.js

線上預覽 GitHub

幫顧客在一間全聯門市找商品的原型。支援同義詞的模糊搜尋，會顯示每項商品所在的走道和貨架，雙語介面在手機和電腦上都能用。

Taiwan Fare Finder

Flutter, Dart, TDX API

GitHub

用 Flutter 開發的 App，透過 TDX API 的即時資料比較全台大眾運輸票價（高鐵、台鐵、捷運、公車和 YouBike），支援離線快取和多種語言。

Prambanan Batik

PHP, MySQL, Vanilla JS

GitHub

印尼蠟染布（batik）的商品目錄與評論網站，有後台管理、CSV 批次匯入、SEO 用的 sitemap 和 robots.txt，以及防止暴力破解登入的機制。

Three Frogs

PHP, MySQL, jQuery

GitHub

為泗水一間桌遊咖啡廳製作的網站。顧客可以瀏覽約 218 款桌遊、註冊帳號並預約桌位，預約時段和取消規則由伺服器端控管。
